# 市场状态规则 · 云端v1

> 2026-10-22 起草。蓝图「理解层 · 市场状态」模块的程序部分：每个交易日收盘后由 GitHub 服务器算指标、按下面写死的规则给出**规则结论**。规则结论只是指标的归纳，不是判断记录；Claude 的判断在 M3 接进总控时另写判断记录。
>
> 这是新写的规则，没有沿用 Mac 上股票助理的阈值（那份代码没读到）。阈值改动要升版本号（云端v1 → v2），并在文末“变更记录”写一行；参数都在 `scripts/market_state.py` 顶部的 `RULES`，改这里也要改那里。

## 一、输入（都在 `data/` 下）

| 指标 | 来源 | 说明 |
|---|---|---|
| 两市成交额 | 东财行情（上证指数+深证成指的全市场成交额） | 当天收盘后取；历史由 qlib 开源数据集回补，标 `回补估算` |
| 涨停、跌停、炸板、最高连板 | 东财涨停/跌停/炸板池 | 历史由 qlib 按涨跌幅推算回补，标 `回补估算` |
| 融资余额 | 东财两融汇总 | 晚一个交易日公布，用最新一天 |
| 沪深300 | `data/行情库/指数/sh000300.csv` | 价格指数 |
| 行业 ETF | `data/行情库/ETF/`，清单里 group=行业ETF 的标的 | 成交额用 成交量×收盘价 近似，只比相对变化 |

## 二、大盘攻守（攻 / 中性 / 守）

七个信号，各记 +1 / 0 / −1：

| 组 | 信号 | +1 | −1 |
|---|---|---|---|
| 趋势 | 沪深300 与 60 日线 | 在上方 | 在下方 |
| 趋势 | 沪深300 与 20 日线 | 在上方 | 在下方 |
| 趋势 | 20 日线方向（今天比 5 个交易日前） | 向上 | 向下 |
| 资金 | 成交额 ÷ 前 20 日均 | > 1.10 | < 0.85 |
| 资金 | 融资余额 5 日变化 | > +1% | < −1% |
| 情绪 | 涨停数 − 跌停数 | ≥ 30 | ≤ 0 |
| 情绪 | 炸板率 = 炸板 ÷（涨停+炸板） | — | ≥ 40% |

- **攻**：总分 ≥ 3，且沪深300 在 60 日线上方。
- **守**：总分 ≤ −2；或沪深300 同时在 20 日线和 60 日线下方。
- 其余为**中性**。

意思：趋势是底，资金和情绪是确认。趋势坏了（两条均线下方）不看别的直接守；要攻必须站在 60 日线上，并有资金或情绪配合。

## 三、冷热（过冷 / 偏冷 / 正常 / 偏热 / 过热）

| 热信号 | 冷信号 |
|---|---|
| 成交额在近 250 个交易日的分位 ≥ 90% | 分位 ≤ 10% |
| 沪深300 偏离 20 日线 ≥ +6% | ≤ −6% |
| 最高连板 ≥ 7 | 跌停 ≥ 50 |
| 涨停 ≥ 120 | 涨停 ≤ 20 |

热信号 ≥2 个为过热、1 个偏热；冷信号 ≥2 个为过冷、1 个偏冷；冷热信号同时出现写“分歧”，按正常处理；都没有为正常。

## 四、板块：主线、资金流向、拥挤度（行业 ETF 近似）

- **主线**：近 5 个交易日里至少 3 天当日涨幅进前 5，且 5 日涨幅 > 0。
- **新启动**：今天涨幅进前 5，今天成交额是前 20 日均的 1.5 倍以上，且不在主线里。
- **资金流入/流出前 5**：近 5 日成交额占全部行业 ETF 的比重，减去之前 20 日的比重（百分点），最高 5 个为流入，最低 5 个为流出。
- **过热板块**：5 日涨幅 ≥ 15%，或收盘偏离 20 日线 ≥ 15%。
- **拥挤**：近 5 日成交额占比处在它自己近 250 个交易日的 90% 分位以上。
- **风格**：每个 ETF 标一个风格（成长 / 周期 / 消费 / 金融 / 稳定），按风格汇总 5 日涨跌（等权平均）和成交占比变化，占比上升最多的风格写成“资金在往哪流”。
- 每个 ETF 尽量对应到命脉股票池的 12 个行业之一（清单 note 里写 `行业=`），方便和产业地图、驱动图谱对照。

## 五、产出

- `data/市场状态/日指标.csv`：每个交易日一行的原始指标（只追加；回补的行 `来源=回补估算`）。
- `data/市场状态/<年-月>/<日期>.json`：当天完整结果；`data/市场状态/最新.json`、`最新.md`：最新一天。
- `logs/市场状态_规则检验.md`：用历史数据按本规则逐日算出攻守，统计之后 20 个交易日沪深300 的涨跌和最大回撤，看规则有没有区分度。

## 六、已知限制

- 行业 ETF 只是行业的近似，成交额也是估算，资金流向是“交易活跃度在往哪移”，不是真实的主力资金。
- 回补的涨跌停数按涨跌幅推算，ST 股（5% 涨跌幅）和新股首日会有误差。
- 这套规则是起点，不是结论。用于仓位开关之前，必须先按固定口径回测，并跑赢同期红利和红利稳健配置。
