# 散户情绪规则 v1

> 2026-10-22 起。散户情绪模块的全部口径都写在这里：温度计怎么算、文本指标怎么数、阶段怎么判、什么时候通知。
> 改任何一条都要把版本号加 1（v1 → v2），并在末尾“改版记录”写明原因；改版前后的指标不能直接比较。
> 关键词表在 `system/情绪词典.json`，改词典同样要升版本。

## 一、定位

散户情绪是推演系统**理解层**的一个模块，回答“大众现在是什么心理、处在哪个阶段”。它不单独给买卖信号：

- 2026-10-22 回测（研究档案案例 78）：温度计单独当开关，冷买热卖沪深300 两版没跑赢红利；红利·过热避险只跑赢红利 0.27 个点，前半窗口略输。
- 所以它的用法是：**温度计发现极端，文本确认这个极端是不是到头了**；结论写成判断记录，到期复核打分，攒够样本后再回测。

## 二、数据（程序抓，Claude 不手填）

| 数据 | 位置 | 时间 |
|---|---|---|
| 热度榜、股吧/集思录帖子正文和回复、tophub 财经热榜、微博热搜 | `data/社区情绪/<日期>/` | 工作日 15:37（`community-sentiment.yml`） |
| 成交额、涨跌停 | `data/市场状态/日指标.csv` | 市场状态工作流（约 17:20） |
| 融资余额 | `data/市场状态/融资余额.csv` | 次日公布，温度计滞后一天用 |

## 三、情绪温度计（行为指标，程序算）

温度 T（0–100）＝下面三项各自在过去 **750 个交易日**（含当天）里的分位数，取平均：

1. 成交额热度：全A成交额 20 日均值
2. 杠杆热度：融资余额 60 日变化率（用前一交易日的融资余额）
3. 赚钱效应：（涨停 − 跌停）20 日均值

和案例 78 回测用的是同一个公式，保证实盘读数和回测可比。

| 区间 | 温度 | 含义 |
|---|---|---|
| 冰点 | < 20 | 历史上的底部区域（2018-10、2022-04、2024-02 都在这里） |
| 偏冷 | 20–40 | |
| 中性 | 40–60 | |
| 偏热 | 60–80 | |
| 过热 | ≥ 80 | 历史上的阶段顶部区域（2019-04、2020-07 都在 90 以上） |

已知缺陷：放量急跌时成交额分位会把温度拉高（2020-03 疫情急跌温度 84），所以温度高、指数却在急跌时，要看文本区分“过热”和“恐慌放量”。

## 四、文本指标（程序数，口径见词典）

每天从当天的 `讨论原始.jsonl`（股吧评论最多的 20 帖、集思录热门 10 帖的正文和回复）、`股吧上证吧帖子.csv`、`微博热搜.csv` 计算：

| 指标 | 算法 |
|---|---|
| 股吧讨论量 | 上证吧最新 80 帖的阅读合计、评论合计 |
| 回复数 | 当天抓到的回复条数（股吧+集思录） |
| 恐慌词率 | 回复里命中“恐慌”词表的条数 ÷ 回复数 |
| 贪婪词率 | 命中“贪婪”词表的条数 ÷ 回复数 |
| 抄底词率 | 命中“抄底”词表的条数 ÷ 回复数（单列，因为既可能是贪婪也可能是自嘲） |
| 求助词率 | 命中“求助”词表的条数 ÷ 回复数（问点位、问能不能拿、求帮看票） |
| 情绪差 | 恐慌词率 − 贪婪词率 |
| 微博出圈 | 微博实时热搜里命中“财经出圈”词表的条数 |

每项另算在已有历史里的分位数；历史不足 20 个交易日时只记录、不用于触发。

## 五、阶段判读（Claude 判，按标准写）

下跌一侧的五个阶段，上涨一侧的五个阶段，外加“中性”。判读时**先写观察到的证据，再给阶段**，至少引用 3 条原话（每条不超过 30 字）。

| 阶段 | 可观察的标志 |
|---|---|
| 否认 | 喊“洗盘”“V 反”“下午拉回来”的多，且没人反驳 |
| 愤怒 | 骂制度、骂机构/量化/外资、骂博主的多；对政策表态嘲讽 |
| 讨价还价 | 问点位、问“守不守得住”、问能不能解套、求博主帮看票的多 |
| 认命 | “毁灭吧”“不看了”“放着收股息”“亏麻了”；骂的力气都没了 |
| 冷清 | 讨论量、回复数降到低分位；抄底帖没人骂而是没人理；“销户”“离开股市”出现 |
| 怀疑 | 上涨中仍以“反弹而已”“诱多”为主 |
| 希望 | 开始有人说“底部确认”，但喊多的会被反驳 |
| 乐观 | 晒收益多了，回调被说成“上车机会” |
| 兴奋 | 讨论量高分位，“满仓”“加仓”“翻倍”多，新人问开户和买什么 |
| 狂热 | 财经话题频繁上微博热搜、借钱加杠杆、看空的人被群嘲 |

判读时还要写：恐慌是否在**钝化**（指数新低但恐慌词率没新高）、讨论是否在**冷清**、不同社区是否**分歧**（股吧 vs 集思录）。

## 六、触发条件（程序判，写进 `data/社区情绪/触发.json`）

满足任一条即为“触发日”：

1. 温度**进入或离开**冰点区（上穿或下穿 20）
2. 温度**进入或离开**过热区（上穿或下穿 80）
3. 温度单日变化 ≥ 15
4. 微博出圈 ≥ 2 条
5. 恐慌词率或贪婪词率处在历史 95% 分位以上（历史 ≥ 20 个交易日后才启用）
6. 讨论量处在历史 5% 分位以下（冷清候选；历史 ≥ 20 个交易日后才启用）

## 七、通知（什么时候打扰你）

| 时间 | 谁 | 做什么 | 推送 |
|---|---|---|---|
| 每个交易日约 17:30 | 程序 | 算温度计和文本指标，更新 `data/社区情绪/最新.md`、`触发.json` | 不推送 |
| 每个交易日 18:13 | Claude（定时任务“散户情绪·触发判读”） | 只在触发日工作：按第五节判阶段，写 `<日期>/情绪判读.md`，温度在冰点或过热区时写判断记录 | 触发日推送，其余日子什么都不做 |
| 每周五 19:23 | Claude（定时任务“散户情绪·周报”） | 一周温度走势、阶段变化、钝化/冷清/分歧，写 `周报/<日期>.md` | 推送一条短的 |
| 你问市场时 | Claude | 回答里附一行：温度、区间、最近阶段 | — |

## 七之二、判断记录

触发日且温度 < 20 或 ≥ 80 时，写一条判断记录（`module`=散户情绪，`scope`=市场/沪深300，`horizon`=月，复核日 = 20 个交易日后）。例：

- 冰点 + 冷清：claim“沪深300 未来 20 个交易日内不跌破本日收盘的 95%”；falsify“收盘跌破本日收盘的 95%”。
- 过热 + 狂热：claim“沪深300 未来 20 个交易日内出现 ≥5% 的回撤”。

复核时按阶段统计命中率，用来检验阶段判读到底有没有用。
