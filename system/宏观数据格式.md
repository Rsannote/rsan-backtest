# 宏观数据格式 v1（T6b）

依据PR #12的Claude审核决定。原始指标放`data/宏观/<指标>.csv`，字段为`date,value,source,可见日期,可见时刻,note,记录时间`；date为来源观测日或月度统计期（YYYY-MM），不是发布日期。可见时刻一律北京时间，真实发布日期未知时保持未知，不用抓取日冒充。source存实际取数网址，单位及一级/二级来源见该目录说明。

| 指标 | 单位/口径 | 主来源 | 可见规则 |
|---|---|---|---|
| 中国10年国债 | %，中债国债到期收益率曲线10年 | 中债官方；东财每日对照，差值>0.5bp记警告 | 观测日18:00 |
| 美国10年国债 | %，DGS10恒定期限 | FRED（原始来源美联储H.15/美国财政部）；东财对照 | 美国日期D之后严格下一个A股交易日09:30 |
| 美元兑人民币 | 人民币/美元，中间价 | 外汇交易中心 | 当日09:15 |
| 美元兑人民币_FRED历史补充 | 人民币/美元，纽约午间价 | FRED DEXCHUS；仅补历史，和中间价分文件 | 观测日之后满7个自然日，再取下一A股交易日09:30；非真实发布时间 |
| 美元指数 | 指数点 | Yahoo DX-Y.NYB，二级 | 当地日期D之后严格下一个A股交易日09:30 |
| 布伦特原油、COMEX黄金 | 美元/桶、美元/盎司，连续合约 | Yahoo BZ=F、GC=F，二级 | 同上；note注明“连续合约，换月有跳空” |
| M1、M2 | 亿元，期末余额 | 东财，二级 | 统计期次月15日收尾（23:59:59），规则推定 |
| CPI同比、PPI同比 | %，全国同比 | 东财，二级 | 次月15日收尾，规则推定 |
| 制造业PMI | 指数点 | 东财，二级 | 次月1日收尾，规则推定 |

09:30是A股开盘时的可见边界；月度只取得日期时，使用该日收尾，不用于当日盘中。月度规则沿用审核指定日期，不伪造真实发布时刻。Yahoo按来源regular session结束时刻排除未完成日线；无该字段的历史日按当地18点收尾保守过滤，盘中未完成K线不落档。来源有修订时另追加同date的新行，修订可见时刻不早于本次观察到修订的时刻，已有字节不改。初次建库的历史可能包含来源事后修订，不能声称有历史逐日版本；历史推定可见日期也不能消除这种限制。

外汇交易中心历史接口实测403，当前中间价从启用日开始积累。FRED历史补充不是中间价，不拼成同口径曲线；其可见日为保守估计，也不是已核验的逐日发布日。M1自2025年起统计口径调整，分段注明，不跨断点解释增长；本次只存余额，不计算M1同比。

`派生.csv`存中美10年收益率20个**A股交易日**变化（bp）：按每个A股交易日18:00，向后查找各自已可见的最新观测，比较严格20个A股交易日前的已可见值，百分数之差乘100。保留起止A股日期、两端真实观测日期和来源，不把海外休市日伪造成新观测；不得向前查找或填未来值。未满20日不产出。数据用于主线雷达环境维度，不给任何判断或买卖建议。

每日北京时间09:35、18:35更新，含周末（月度发布与海外日历不同）；运行时刻不是数据可见时刻。T2登记运行报告，以报告成功时间检查工作流新鲜度，源失败与对照缺口另列；初期无运行样本，暂借现有已审核任务的最大宽限，不声称本任务已完成P95校准。正式宽限不得因此改动其他任务。
