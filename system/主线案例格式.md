# 历史主线案例格式 · T14草案v0

T14是事后案例库，不判T15阶段、不生成判断或买卖建议。核心依赖只有已合并的T8日表与T9公共特征；T13历史28表仅提供启动前五维读数，缺业绩/EPS/新闻/市场状态不阻止案例识别，不读取T13b或T12b未合并分支。

## 固定观察集合与日条件

读取`system/行业清单.csv`，排除2021新增的801960/801970/801980，整个历史固定28行业；综合801230只参与成交占比分母，不进入候选与排名。实际候选27个，不拼接历史28与当前31数据，也不使用ETF代理。

`data/资金轮动/日表.csv`必须按文件顺序先取`date+code`最后一行，再做任何日期/行业筛选、排序、转数值、聚合与排名。最后修订为空也保留为空，不能回退旧值。60日强弱直接使用T8的`相对沪深300_60`，重新在27候选降序排名，不使用T8包含综合的旧排名；所有候选有效才给全排名。同值按代码升序。没有增加绝对/相对收益为正的条件，负收益行业也能相对领先。

成交占比直接使用T8的`占比_28`，28行业含综合均有效、非负且合计与1的误差不超过1e-7时，才在27候选中降序排名。阈值为`rank/27 <= .20`，即前5，不向上取整成6。1e-7只校验上游CSV舍入误差，不是新的经济参数；不重算或回填T8占比。

相对全排名前3且成交占比前5为实际命中。任一完整排名条件已失败为已知不成立，即使另一条件缺；没有已知失败且任何条件无法完整排名为未知。沪深300交易日历中的T8整日缺行仍保留为未知日。缺不填0、不排末尾、不把有效样本排名冒充全排名。

## 40实际命中、5桥接与成立/结束

独立参数文件是`system/主线案例参数.json`，默认草案固定3 / .20 / 40 / 5；不写T15的`system/主线参数.json`，不为公开案例调参。

从首次命中开始，连续最多5个非命中交易日可以桥接；非命中中可含未知。桥接不前填，不计入40实际命中。第40个实际命中日为`成立日期`，之前不会产出已成立案例；`开始`是事后回溯的首次命中日，不能冒称当时可交易的信号。`结束`是最后一个实际命中日。

连续第6个非命中日切开可连接段。若这6天全为已知失败，状态为`已确认结束`，确认日期为第6天；若混有未知，状态为`数据中断待核实`，确认日期留空，不能据此声称退潮。末尾尚不足6天断开则保留`待中断确认`；末尾含未知则为`数据不足待确认`，计算截止明确列出。两种末尾状态都不把未确认段删掉。若后续源修订补齐，重算并追加状态版本。

同时输出三个不同数量：`实际命中交易日`只数True；`桥接跨度交易日`为开始至最后命中含两端的跨度；T9公共`持续交易日`是沪深300端点索引差（跨度减1）。桥接已知失败/未知与尾部已知失败/未知分列，不能靠桥接跨度凑40日。

## 价格统计与同期第二强

行业价格统计独立读取已存`data/资金轮动/原始/申万/<代码>.csv`的`close`，每个`date`也先取最后修订；沪深300读取`data/行情库/指数/sh000300.csv`的`close×factor`。原始价格只供统计，不回填T8识别条件。

幅度是本行业价格指数的结束收盘/开始收盘减1，不含分红。区间超额是该价格收益减同期沪深300价格收益，**不是净值比之比**。公共启动前60/120日涨幅针对本行业，要求对应交易日窗口价格完整；其余公共启动特征复用只读T9助手（开始日18:00）。融资余额严格前一A股日，宏观按T6`可见时刻`过滤，来源JSON保留实际观测日期，不把缺数补0。

`同期第二强的行业`在相同开始/结束日期上，对全部27候选的价格收益减相同基准收益排序，**包括本行业本身**，取整体第2；可能就是本行业。它不是“除本行业外最强的同行”，不从已识别案例挑对照。全部27候选两端价格均有效才给完整第2；某候选端点缺则第2留空，列出缺代码。中间某天缺价不影响精确端点收益；没有额外要求每一天价格齐全。同值按代码升序。

## 五维窗口、可见性与人工字段

`启动前20日五个维度的读数`是JSON，明确T-20..T-1，严格排除开始日，逐日保存环境适配、业绩预期、热度催化、资金、拥挤度的原字段值，以及每字段有效日数、实际覆盖日数、来源和缺行。数字保留T13来源字符串精度，缺值为null。没有用平均数掩盖缺数，也不以缺为业绩未加速。最早样本不足20日会明确覆盖数。

T13表也先取`date+code`最后修订。五维是各观测日23:59:59日末读数，宏观、市场、社区若可见时刻缺时区、缺失或晚于该观测日日末，会屏蔽相应数值并列说明；上游原始维度状态只供追溯，不冒称屏蔽后重算状态。`启动时大盘攻守`读取开始日日末已可见的同日T13存档，无记录留空。T9公共宏观特征与此五维日末窗口的18:00/23:59:59基准分别标明。T8/T13最后修订历史不等于严格时点数据库。

兼容T13b约定：本任务专用I/O先读原基表`data/主线/历史信号表_28.csv`，再按文件名升序叠加`data/主线/历史信号修订/<YYYY>.csv`，跨文件同date+code以最后一行整行替代，最后修订的空值同样生效，不能按列回填旧值。不存在分片目录时保持基表行为。读取器同时支持31口径的`信号表.csv`→`信号修订/<YYYY>.csv`；当前案例仍只读取28口径。没有导入未合并的T13b模块、不改T13b输入输出，实际读取的分片路径列入来源与SHA256清单；T13b未来合并后仅更新五维附属读数，不改变T8核心识别条件。

公共人工列以及新增`上位类型`、`支撑`全部新建留空。更新按事件id保护历史每列最近的非空人工内容，即使最后一条记录该人工列为空，也不会擦掉较早非空判读。缺失说明和规则状态只写程序列。

## 只追加、回放与验证

`主线.csv`严格保留旧字节前缀，同输入同状态不重复追加；输入修订令旧案例消失时追加`输入修订后不再满足`版本，旧数据与人工判读继续保留，现行总表不再计入。`主线_总表.md`按时间排序现行版本，每次内容变化只追加一个带分隔符的完整快照，最后一个快照是现行总表。

写入用标准库`fcntl`互斥：同根目录的完整run串行，CSV单独追加也对整个读取旧字节→比较→写入持锁。锁放系统临时目录，不写data或追踪文件，不删除锁inode以免等待者与新调用分裂成两把锁。真实多进程回归核对每次成功追加均保留历史版本及已有非空人工判读。

运行：`python scripts/mainline_cases.py --backfill`。可用`--root`在隔离副本生成；`--asof`仅限定计算截止，不声称历史逐日原始版本。已有输出截止晚于本次则拒绝截短：同时检查建库报告和总表全部快照的全局最高截止，报告缺失时仍从总表核查，不能因所有事件较早结束而允许全局倒退。另保留逐事件截止保护，所有拒绝均发生在数据写入之前。脚本不联网。建库SHA256清单、日条件覆盖和六组固定公开窗口对照在`logs/test/T14/`。

`tests/test_mainline_cases.py`验证阈值、5/6断点、未知桥接、最后空修订、综合分母、前5定义、负收益领先、五维T-20..T-1/时点、第二强精确端点、CRLF旧字节/最近非空人工保护、失效修订/恢复、隔离全流程及重复幂等。`tests/verify_t14_cases.py`用独立命中位置分组校验真实18段并输出固定窗口对照。一手公开文档只支持其叙事与样本口径，不能代替日度草案验收；2015个别全文未复验、2019–2021分期支持、2024不同红利代理的反证全部如实列出。

新工作流仅为只读权限的手动/PR验收，不新增定时生产调度，不改主运行清单或T11/T12b/T13b。公开PDF重取测试只允许在GitHub Actions，下载与回执留测试目录及artifact，不自动提交数据。

## 待Claude审核的歧义

- 成交占比“前1/5”采用候选rank/27<=.20（前5）；另一选项是包含综合排名或向上取整前6，本版不混用。
- 持续40采用实际命中，不采用含桥接跨度；两者同时输出供审核。
- 最多5日非命中可包含未知，但未知不能确认退出；混未知达到6日仅中断待核实。不得按公开匹配结果临时更换口径。
- 同期第二强采用含本行业的整体第2；若要比较“除本行业外最强”，需明确改字段/口径后另审。
- 起点五维用20个逐日原值而非平均值，历史最后修订含时点限制；未来交易回放仍须T15另审。
