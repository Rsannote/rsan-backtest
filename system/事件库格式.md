# 事件库公共格式 v1（T9/T14）

公共字段按开发计划v2：`事件id,类型,对象,开始,结束,幅度,持续交易日,启动前60日涨幅,启动时成交额分位,启动时融资余额变化,启动时情绪温度,启动时中国10年国债,启动时美国10年国债,触发事件,传导链或上位类型,资金驱动或事件驱动,退潮原因,备注`。类型限定大调整/大反弹/主线；T14可以追加行业专属列。

兼容T9原要求，另保留`传导链`列。`触发事件、传导链或上位类型、传导链、资金驱动或事件驱动、退潮原因、备注`这六个文字列，新记录全部留空，由Claude以追加修订行填写，程序保留既有非空内容。程序缺失说明写在额外的`程序说明`列，不占人工判读列。

比例字段使用比例值（-0.15=-15%），成交额分位/情绪温度为0–100，中国/美国10年国债为百分数（2.0=2%）。持续交易日是两端在沪深300日期序列中的索引差，开始日不计数。开始/结束为事后识别的峰/谷日期；`成立日期`记录首次越过幅度阈值日，`确认结束日期`记录反向幅度确认极值的日期，不能把极值日期当成当时已知的交易信号。

其他列包括启动前120日涨幅、启动/结束20日成交额均值及变化、启动/结束融资余额及变化、特征来源JSON、状态、计算截止、追加时间、更新原因、程序版本。缺数据留空，不填0。来源JSON保留各数值实际观测日期、来源路径、可见时刻及回补估算标记。

## 划段

沪深300收盘价×factor，从2005年已存首日开始。局部转折采用对称15%方向变化：下降段从局部最高收盘跟踪最低收盘；峰谷跌幅达到15%成立，谷底之后反弹达到15%时确认下降段结束；上升段跟踪最高收盘，随后回撤达到15%时确认上升段结束。反弹表额外只保留谷到峰涨幅达到20%的段，成立日期另取第一次达到20%之日。首次方向由第一组满足转折阈值的峰谷确定，首段标注左边界限制。相同高/低值取首次日期，机器精度仅用于比较边界，不改变经济阈值。

主表`大调整.csv`为15%下降段，`大反弹.csv`为其中幅度达到20%的上升段；`大调整_10.csv`另用对称10%转折划段，属于独立敏感性表，不能重复混入主表对照。未出现反向确认的末段保留“待反向确认”，结束字段仅表示截至目前的极值，另列计算截止；后续变化按同事件id追加版本。闭合事件计算截止固定为确认结束日，避免每日追加相同记录。

这里识别局部调整段，一个长期熊市可以含多段，不按年份手工拆分。另一种“等20%反弹才确认下降结束”的口径会把2021—2024连成一段，无法单列2022的两次局部调整；其初步结果保存在logs/test/T9作口径比较。本PR的转折定义待Claude审核，并未作为仓位或买卖规则启用。

## 启动特征与当前对照

特征基准为开始日18:00。60/120日涨幅严格按沪深300交易日；成交额分位沿用市场状态250条历史窗口、至少120条有效值的口径，20日均值要求完整20个交易日。融资余额使用严格前一交易日及更早的已存数据（防止当日收盘余额尚未公布），5个交易日变化保留实际观测日。情绪使用不晚于基准日的已存最近值；2017年前为空，来源日期不伪装成当日。

宏观严格按T6的`可见时刻`向后查找，来源修订在可见后才生效；2015年前为空，不补造。首次建库历史可能包含来源修订，金额有回补估算，不声称完整时点数据库。

“当前”取已存行情且已到18:00的最近A股日，明确列出基准日期及源日期，不把旧行情称为今天。主对照使用两主表中已确认结束、六个公共特征完整的历史事件：60日涨幅、成交额分位、融资余额5日变化、情绪温度、中美10年国债。只用历史候选计算均值与总体标准差，标准化后计算欧氏距离；常数维贡献0。不填补缺失、不按剩余少数维度混排；缺失/未结束的事件逐一列为未参与，完整候选不足5个就如实少列。附表单独给10%事件距离。解释栏仅写`【待判读】`。

事件库是事后区间统计与案例对照，不是策略回测，不自动填归因、上位类型、驱动或退潮原因。原CSV只追加；数据/状态变化追加版本，保留原字节与人工文字；同输入重跑不重复。
